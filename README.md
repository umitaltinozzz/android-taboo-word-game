## Overview

A native Android Taboo-style word game. The project includes a local word data asset, Android screens, Java source code, and a Gradle project structure suitable for opening in Android Studio.

## Project Status

Completed coursework project, archived as part of my portfolio. Not actively maintained.

## Features

- Implements a Taboo-style word game flow
- Uses local assets for word/game data
- Includes native Android activities and resources
- Demonstrates simple game logic in a mobile application

## Tech Stack

| Layer | Technology |
|---|---|
| Platform | Android |
| Language | Java |
| Database | Local SQLite/data asset |
| Build | Gradle |

## Getting Started

1. Open the project in Android Studio.
2. Sync Gradle.
3. Run the app on an emulator or Android device.
